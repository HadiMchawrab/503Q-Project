# ShopCloud Frontend Package

This is the frontend teammate's package. It contains only the customer storefront and admin dashboard files under `web/public/`.

Frontend-owned files:

- `web/public/index.html`
- `web/public/admin.html`
- `web/public/styles.css`
- `web/public/app.js`
- `web/public/admin.js`
- `web/public/assets/`

Keep frontend API calls under these route groups unless the backend owner agrees to change them:

- `/api/auth/`
- `/api/catalog/`
- `/api/cart/`
- `/api/checkout/`
- `/api/admin/`
